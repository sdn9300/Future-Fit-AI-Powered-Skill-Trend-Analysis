## Troubleshooting

**"Google Calendar API has not been used in project... or it is disabled":** Go to console.cloud.google.com > APIs & Services > Enable APIs > search "Google Calendar API" > Enable.

**"Request had insufficient authentication scopes":** Delete `token.json` and re-run. The old token does not have the calendar scope.

**Gemini returns wrong dates:** Make sure today's date is injected into the prompt. Check that `datetime.now().strftime("%Y-%m-%d")` is being used.

**FreeBusy always returns "free":** Ensure timezone info is appended to times ("Z" suffix). The FreeBusy API requires timezone-aware datetimes.

**Book Meeting button does not appear:** Category must be exactly `"meeting-request"` (hyphen, lowercase). Check what triage.py emits.

**create_event fails with 400 error:** Make sure attendees field is conditional -- only included if valid emails exist. Empty attendees list causes API errors.

**Event at wrong time:** If your timezone is not UTC, change `"timeZone": "UTC"` in the event body to your local timezone (e.g., "Asia/Kolkata").
